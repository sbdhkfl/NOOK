# Contributing to NOOK

Thanks for helping improve NOOK!

## Before contributing

1. Read the README and the project's security guidance.
2. Open an issue first for major features or architectural changes.
3. Keep changes focused and explain the problem they solve.
4. Never submit passwords, API keys, tokens, private user data, or real production secrets.
5. Make sure you have the right to submit the code, documentation, images, and other materials in your contribution.

## Pull requests

- Describe the change and why it is needed.
- Include tests for behavior changes when practical.
- Run the relevant lint, test, and build commands.
- Update documentation when setup, behavior, or configuration changes.
- Keep accessibility, privacy, and security in mind.
